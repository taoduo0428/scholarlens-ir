# E9.1 研究协议与集成基线

负责人为项目组长。接收输入为用户原问题、服务端许可的论文范围和有向无环问题图。输出为逐节点字段、经原文回读的证据关系、可追溯的综合判断及字段缺口。服务端使用独立策略版本 E9.1。验收使用原有英文、中文和历史题，再加入新的多文献独立组。V1、V5、E9、E9.1 在同题使用同一工具限额、模型配置、语料和许可范围。

## 预注册的独立实验

从固定语料中排除 V3、Review、种子、V4 和 E9 英文及中文用过的论文，再按哈希取样。两篇一组，配同一中文综述、指定原句和缺失版面问题。另用一组受控综述题考查双来源方法与结果、单来源缺失以及研究差异。研究运行时只接收题目、许可范围及原文。评分脚本在返回后检查原文和来源，考查综合项的前提血缘。人类学术判断统一留待双人独立评审及裁定。协议冻结后再开发与开启独立组。

## 验收条件

- 单字段、复合字段、多论文多指标、比较依赖及多跳节点分别核验。字段有可解释的归属和来源约束。拒绝无关证据、重复计数及跨节点复用。
- 综述同时给出原文观察和有前提的推导，标出冲突、局限与假说，API、导出和页面共享最终判定。
- 版面无法读取时停止该项，保留其他字段。恢复时检查初始计划、版本和摘要，兼容旧状态。
- 人工标注材料包含 102 道 Review 题和优先复核的 9 道历史题。工具必须报告未标注数量，对无金标准的指标返回缺测。
- Runtime、权限、凭据、观测和交付依次审查，在最终报告逐项列出测试与遗留条件。
