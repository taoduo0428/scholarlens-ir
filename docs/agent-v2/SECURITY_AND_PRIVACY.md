# 来源、权限与日志

研究 API 每次使用现有账户认证读取 owner。对外请求中的 scope 只缩小当前用户可见的集合。公开语料走绑定的具体索引，私人上传额外核对账户及已索引状态。每次读取研究任务、事件、报告、资料均查询 owner，错误回复统一。

个人模型凭据通过旧版已验证的 HTTPS 客户端使用。Worker 在进程内暂存请求配置。恢复已有模型任务时需重新提供凭据并匹配绑定模型。SQLite 只保留模型标识、研究输入、受限状态、执行摘要和证据。用户填写的研究目标属于任务资料，应使用本地账户权限保护数据库及备份。LangGraph 的内部状态只记录 owner、任务号和路由。调用在本地 tracing 上下文中关闭外发。

论文片段进入证据库存储。决策上下文仅接收来源标识、定位与槽位摘要。提议动作经过 Pydantic、范围、预算和运行时工具注册表共同校验。机器技能与策略均需经过离线实验与操作员门禁。[攻击输入、预算、凭据与权限回归](evidence/p3/worker-and-boundaries.txt) · [技能门禁记录](evidence/p6-p7-ablation/README.md)
