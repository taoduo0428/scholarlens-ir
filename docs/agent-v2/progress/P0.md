# P0 验收

本阶段建立了可重复使用的旧系统基线。版本、四分支来源、代码风险与环境边界见[基线总览](../BASELINE_AUDIT.md)。

| 范围 | 结果 | 工件 |
|---|---|---|
| 旧搜索、RAG、账号、个人模型、向量、PDF | 主套件 414 passed / 5 skipped，另用专用环境 5 passed，两个命令退出 0 | [后端命令及退出码](../P0_BACKEND.md) |
| 旧 Agent Harness | 原为 10/11，修复后 11/11，15 个 pytest 实例通过 | [逐项输出](../evidence/p0-backend/harness-after.json) |
| 既有网页 | 45 个单元测试、typecheck、build 和桌面/390px 浏览器验收通过 | [前端命令和输出](../P0_FRONTEND.md) |
| 语料与性能基线 | 四分支 SHA、本地 4,000 个唯一 ID 和八查询历史延迟的适用范围已记录 | [源码和语料审计](../P0_SOURCE.md) |

变更包括 backend/tests/test_agent.py、backend/tests/test_agent_harness_reporting.py、backend/tests/test_papers_integration.py、tools/agent/run_harness.py、frontend/tests/browser-smoke.mjs，以及本阶段文档与证据。只有本机测试环境产生了新账号、数据库、索引与向量。任何后续真实线上部署、真实线上数据库和收费提供商验证均需单独授权。

性能基线取实测环境，未将单元测试数量用于证明研究质量。P1 的准入依据包括可复现的历史端点、稳定的 11-case 清单、隔离运行目录和可读取的 corpus 数据。
