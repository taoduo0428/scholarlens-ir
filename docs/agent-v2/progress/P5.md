真实 HTTP 验收使用两篇 fixture 论文。Cedar 和 Birch 的评估指标分别为 precision at five 和 recall at ten。初次执行生成 4 条结论。补入不可比断言后捕捉到遗漏，记录在 `live-final.txt`。第一轮修复后产生 partial 报告，6 条结论通过核验，1 条因条件不匹配而不可比，证据见 `live-accepted-final.txt`。

最终构建的工作台提供可折叠的研究目标和子任务，展示完成条件、当前状态与缺口。结论矩阵按后端的子任务和结论 ID 关联原文。报告提供方法和实验对照表；两项主张出现冲突时，能展开另一项主张并读取对应的逐字来源。

最新同源 Chrome 验收生成 completed 报告、4 个子任务、5 条有序事件和 2 条回验来源。测试逐项核对 9 条结论的子任务归属，8 条已核验，1 条不可比。桌面和 390px 下均可定位原文并导出 Markdown，第二账户访问返回 404，页面错误为 0。独立 Mock 场景实际点开了无结论的子任务、协议缺口、相互冲突的两段来源和实验对照表。见 `matrix-build.txt`、`matrix-live.txt` 和 `matrix-mock.txt`。
