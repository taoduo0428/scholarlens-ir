# P4 结论核验与报告验收

本阶段实现逐字来源回读、结构化测量与条件匹配、摘录式命题核验、来源关系和 Markdown 导出。实现文件为 `backend/research/claim_verifier.py`、`evidence_graph.py`、`reports.py` 和 `backend/tests/research/test_claim_report.py`。[实现及选择理由](../P4_CLAIMS.md)

`python -m pytest backend/tests/research/test_claim_report.py -q --basetemp .venv/p4-claims-post-drift` 在隔离 Python 3.11.15 中退出 0，20 项通过。实现中曾遇到自然书写的截断位、代词引用与相邻数据集标签的核验失配，已将冻结示例加入全图回归。示例现在输出 8 个核验后的子任务陈述及 1 个不可比判断。P5 可读取报告中的来源、分区、PDF/正文状态和导出内容。真实论文未见任务的人工支持率尚未测量。[验证与原件（历史归档索引）](../../agent-v3/artifacts/LEGACY_INDEX.md#ref-62da07ae0890)
