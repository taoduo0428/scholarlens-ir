# P1 任务存储与离线基准

本阶段接收认证后的研究输入，将状态、事件、检查点和资料分别保存，并通过旧 Agent 的真实证据流程建立对照。公开种子集含 12 篇论文的 36 个任务，另设两个合成摘要供 smoke 测试。逐字段定义见 [任务契约](../API_AND_STATE_CONTRACT.md)，修改集中在 `backend/research/{schemas,store,flags}.py`、`tools/research_eval`、`agent/benchmarks` 和相应测试。

在 worktree 根目录用 Python 3.11.15 执行 `.venv/Scripts/python -m pytest backend/tests/research/test_schemas.py backend/tests/research/test_store.py backend/tests/research/test_flags.py backend/tests/research/test_eval_p1.py -q --basetemp .venv/verify-p1-root`，退出 0，60 项通过。初次验证暴露了恢复、来源定位和预算回退问题，修复后并发幂等、跨账户隔离、备份恢复与写入竞争均通过。[合并测试（历史归档索引）](../../agent-v3/artifacts/LEGACY_INDEX.md#ref-55d330e29e90) · [存储专项](../P1_STORE.md)
