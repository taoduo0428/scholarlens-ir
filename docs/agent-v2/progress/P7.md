# P7 · 受约束的 Harness 离线策略搜索

2026-11-20。本阶段实现确定性网格搜索、候选配置差异、独立验证、审批门禁和版本回滚。候选在独立 smoke 出现退化，晋升被拒。生产继续使用 bounded-v1。

- 实现集中于 `tools/research_evolution/{experiment,lifecycle,replay}.py`、`backend/research/skills/registry.py`、`tools/research_eval/matched_budget.py` 与门禁回归。候选仅改变硬上限以内的证据条数和补检轮数。运行策略同时支持受控的检索模式。
- 评测数据为 36 个固定公开种子中的 dev 六题，以及独立的六个合成 smoke。三个配置在 dev 依次调用 27、25、23 次工具，锚点覆盖均为 3/7。精简候选每题至多额外一轮、每子问题两条证据。其 smoke 覆盖从 7/7 降至 6/7，审批拒绝。人工质量判断为 0，模型调用和成本均为 0。
- 六种配置预先登记后各在冻结 holdout 运行一次。B0 命中 6/7 个参考块，B2、B4、B5 各命中 4/7 个。B0 和 B2 等预算 dev 对照使用 10 次工具、10 条证据、120 秒和 0 次收费模型的任务上限，分别命中 7/7 与 3/7。现有数据支持报告来源覆盖及延迟，人工可支持性和跨领域泛化仍待独立标注。
- Windows、Python 3.11，项目虚拟环境。正式实验及等预算命令退出 0，P6/P7 独立安全门禁 11 项通过，自有跨阶段 29 项测试通过。grep、ruff、`git diff --check` 和原始结果路径见下方记录。
- P8 以冻结结果、用户入口和故障注入进行系统验收。质量不足或成本不合理的候选保留为实验记录。
