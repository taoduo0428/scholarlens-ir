# P2 论文发现与原文定位

七种有类型约束的研究工具在 LocalCorpus 和 EsCorpus 上运行，论文范围和上传可见性由服务端校验。来源回读重建旧版 chunk，验证字符区间、引文与 SHA-256。修改位于 `backend/research/tools/`、`tools/research_eval/retrieval_experiment*.py` 和对应测试。完整命令、环境和退出结果见 [工具专项](../P2_TOOLS.md) 与 [检索实验](../P2_EXPERIMENT.md)。

真实本地 ES 8.19.23、MiniLM 和 TinyBERT 对 100 篇固定论文完成 8 查询、3 轮的检索实验。HNSW 与精确检索 top 10 的一致性为 237/240。BM25、精确 MiniLM、HNSW、RRF、RRF 加重排的 P95 依次为 5.33、9.53、9.08、14.74、43.37 ms。人工相关性指标留空。真实关键词 API 专项使用独立 859 篇索引。初次 bulk 的磁盘水位故障及重试保留在实验报告中。P3 使用工具返回的固定来源与校验结果驱动补检。[原始测量](../evidence/p2-experiment/retrieval.json)
