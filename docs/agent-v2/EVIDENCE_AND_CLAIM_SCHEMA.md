# 定向检索与引用的数据契约

输入为已认证用户、受限的论文集合、具体语料版本和研究子问题。检索分为论文发现与段落定位。允许按题目、摘要、全文和年份定位。私人论文的归属检查在候选排名前和读取原文时各执行一次。工具层持有这些约束，模型输入仅携带查询或已授权来源 ID。

每个证据引用绑定 paper_id、原有 chunk_id、field、原字段内的绝对字符区间、原文 SHA-256、source_kind、读取权限、generation 和读取时间。读取者重新生成旧版字符片段并精确比对引用和字符区间。PDF 文件可得性由本地 PDF 访问器单独判断。段落排序优先子问题的字词和实际章节标题，可接入只对候选排序的离线模型。

关系图记录子任务、Claim、Evidence、SourcePaper 和有方向的支持关系。判断比较结果时需核实指标、单位、数据集和协议。只有引文存在且陈述在适用条件下有据可核的结论进入已核验区。按来源逐字引用的事实、原文报告的实验结果和跨论文推断应在报告中明确区分。

P2 工具为 search_papers、search_passages、read_paper_metadata、read_paper_chunks、verify_source_quote、extract_method_results 和 get_research_state。P4 补齐单项条件与语义核验。验收覆盖一个字符的篡改、语料版本变更、无 PDF 时的文本引用、无论文范围时的所有者过滤和跨数据集不可比。
