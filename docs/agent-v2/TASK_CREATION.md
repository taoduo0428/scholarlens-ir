# 研究任务创建与恢复契约

`POST /api/research/tasks` 使用已登录的账户和 `Idempotency-Key` 创建任务。省略 `depth` 时采用标准深度。服务器在首次写入任务时保存预算。查询任务详情可查看 `state.budget`。

| HTTP 深度 | 最多轮次 | 最多工具调用 | 个人模型最多调用 | 最多证据条数 | 执行时限 |
|---|---:|---:|---:|---:|---:|
| `standard` | 2 | 16 | 2 | 12 | 180 秒 |
| `deep` | 4 | 30 | 4 | 30 | 600 秒 |

纯证据模式的模型调用上限为 0。轮次从 Worker 开始执行时计起。证据充足、搜索停滞或任一预算耗尽，任务可以提前结束。暂停和恢复沿用任务已记录的预算、已消耗的次数和原截止时间。已经创建的任务读取自己存储的预算。离线评测直接创建任务时继续使用评测自己的固定配置。

同一账户用同键重发相同任务输入，接口返回原任务编号和当前状态。即使检索依赖暂时离线，重试仍可取得这个结果。同键改换深度或其他输入会收到 409。新任务需要取得语料版本，语料离线时返回 503。已经等待个人凭据的任务通过 `POST /api/research/tasks/{task_id}/resume` 提交本次模型配置。

报告和 Markdown 只有在任务状态提交其资料编号后才能下载。单独写入、尚未发布的报告和 Markdown 通过资料接口返回 404。

浏览器跨域访问使用配置中允许的来源。预检支持 `Authorization`、`Content-Type`、`Idempotency-Key` 和五个个人模型请求头，即 `X-ScholarLens-AI-URL`、`X-ScholarLens-AI-Model`、`X-ScholarLens-AI-Key`、`X-ScholarLens-AI-Token-Parameter`、`X-ScholarLens-AI-Protocol`。

后端维护此契约。独立验收覆盖 HTTP 创建时的两档预算、运行中提前停止、恢复后的预算、语料离线的重试与冲突、跨账户的幂等键隔离和指定来源的浏览器预检。[本地回归测试](../../backend/tests/research/test_http_task_creation.py)
