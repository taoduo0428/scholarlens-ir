# 决策、预算与上下文

模型可提出检索、阅读、提取、重排问题和停止。服务端校验提出的目标、动作类型、范围、代次和资源上限。个人模型模式使用原有鉴权渠道与超时，离线路径生成确定性问题图。计划生成允许一次受控修复，第二次失败使用离线计划。模型及来源均无权变更账户、索引、Skill 注册表或任务上限。

新策略为每个已入账来源预留最后一次读取。剩余预算不足以核验下一个候选时提前结束检索，并把完成的来源交给报告器。报告列出工具与模型调用、失败数、已保留的回查次数。供应方成本未知时保留空值。本轮离线回放中调用费为零。

`context_layers.layered` 给出有字节上限的工作视图，优先保留活跃问题与来源引用，然后加入近期检索和决策摘要。超限的内容仍可在所属账户的 checkpoint 找回。原文、实验条件和原文哈希以单独证据工件保存。命名空间包含所有者、访问范围、代次及模型和策略版本。模型视图只使用可信的引用字段，不执行来源正文提出的指令。

暂停或取消的确认事件与对应控制请求的消费在同一 SQLite 事务提交。读取到暂停态后客户端即可恢复，同时到达的取消请求仍具有优先权。验收覆盖 HTTP 重连和已确认暂停的断点恢复。

真实子进程在一个已提交的 round 后退出，重新打开 SQLite 后能继续，前一轮的证据 ID 和哈希一致。可运行 `python -m pytest backend/tests/research/test_process_resume_v3.py -q`。
