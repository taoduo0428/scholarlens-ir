# 问题图、来源与结论

任务契约保存原问题、原始范围、语料代次、语言规范化后的问题、交付物、约束、预算和版本。每个节点包含唯一问题 ID、具体问题、前置问题、来源要求、接受条件与失败条件。允许六个节点和五层依赖。循环、重复节点、越界来源、缺少实验前置条件的比较会被拒绝。稳定序列化用于审计和固定回复回放。

服务端可以按依赖与已知缺口重新安排问题，并记录版本和理由。旧 API 仍通过 Subtask 投影显示进度。执行器支持的来源类型包括元数据、摘要、许可全文及本人上传，权限由注册表检查。报告在发出前再次绑定来源及原文偏移。

|维度|含义|界面|
|---|---|---|
|provenance_valid|最终片段与来源哈希、论文绑定一致|原文已核对|
|semantic_support|离线规则对候选命题的有限支持结论|证据支持、证据不足或与证据矛盾|
|comparison_status|测量是否具备可对齐的数据集、指标、单位、设置和协议|条件已对齐或条件不可比|

V4–V7 对成对出现的否定陈述另核数据集、实验设置与评测协议。三项均显式一致才建立矛盾边，缺项或值不同的观察分别进入待核对照表。V5–V7 在发布定量回答前核对命题本句的量纲和所问计数对象，补充材料与正式回答分开。验收使用单独编写的光学台架夹具，责任人为项目组长。

人类语义判断尚未签核。真实发布的保守规则仍可能抽取一个正确但未回应提问的句子。独立试验已触发拒绝晋升，详见实验记录。
