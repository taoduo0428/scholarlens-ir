# 第二阶段离线评测协议

输入为固定版本的公开论文摘要、用户问题和许可范围。运行器只接收问题及范围，结束后评测器才连接原文锚点。工程负责人为项目组长。

E0 使用六道旧开发题、相同语料及每题 10 次工具上限，分别保存旧流程、新流程证据账本和带发布回查的真实运行。保存工具调用实数、逐题时间、候选和未命中原因。报告按原文片段、论文数及可发布来源计数。缺少逐条人工判断时，P@5、nDCG、语义支持和研究成功率均记为空。

新增验证题按领域家族分组，排除旧 seed 和 review 中的全部论文。冻结文件记录来源、问题、机械定位和摘要哈希，原件及 receipt 只写一次。新未见组在开发时封存，禁止用于选阈值、改提示词或筛选案例。合格标准在查看新未见结果前固定：同一题集、同一访问范围、同一预算上限，发布来源越权与原文校验失败均为零，已知原文定位覆盖和缺失信息拒答均不低于 V1，平均实际工具数不高于 V1 的 110%，预热后 p95 不高于 125%。报告题数及逐题变化。缺独立语义评审、关键指标有退化或无法完成同条件运行，保留 V1 为默认配置。
