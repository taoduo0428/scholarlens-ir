# 跨论文研究手段与证据归属

后端维护者负责 E11 综述中的研究手段比较。输入为本次任务指定的论文及其已核验原句。报告可比较各篇作者如何建立自己的发现，例如用形式证明推导结论，或用数值实验检验方法。每项推断应给出逐篇手段及对应原句，并保留作者限定的适用条件。

验收覆盖两篇和三篇论文、手段相同与不同、研究计划、引述前人、方法名称替换和移除证据。另使用原有 28 组封存论文按相同预算回放，逐条检查发布的关系覆盖范围、出处与字符区间。涉及性能、因果和跨领域外推的结论需要相应的独立证据。

## 2026-11-22 验收结果

E11 现在可以比较作者如何建立自己的模型。例如，一篇论文建模解释网络热度波动，另一篇在模型中引入公共资源与合作贡献的反馈。报告先点明两篇共同使用建模手段，再并列给出论文标题和各自的作者原句。每篇都要有已核验、带来源的模型构建或机制说明。方法名作为背景、只说计划、引述他人以及三篇里缺一篇依据的情形都保留证据缺口。
