# 多跳问题的证据范围

后端维护者负责 E11 多跳任务的证据绑定。输入包括问题中要求解释的实体及关系、用户选择的候选论文和有原文位置的陈述。

用户明确要求说明某一端的输入、方法或因果环节时，该端已核验的陈述可作为局部回答。完整跨篇推断须有来自不同论文的相邻因果环节，中间实体、方向及被请求的两端均应匹配。用户点名的论文及要求覆盖全部论文的任务继续逐篇核验。所有读取都受任务原有授权范围约束。

验收采用固定 111 题、两端各自消融、输入顺序调换、干扰论文和独立论文组，核对每条新发布陈述的论文、原文和位置。

## 2026-11-22 验收

15 道漏答的多跳题每题有 8 篇候选论文，AI Silver 标注各涉及 2 篇。旧报告每题收录了 4 篇，其中 12 题已取到至少一处完整的标注原文。旧版首个来源字段要求同时覆盖 8 篇。这一版按问题中的起点、终点检索候选段落，允许分别核验单篇陈述。对于方法输入，还要在同一篇论文中找到输入声明和该输入对具名方法的影响，才能与另一篇的后续效应连成完整推断。
