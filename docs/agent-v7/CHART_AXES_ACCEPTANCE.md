# 从折线图读取终点

## 接口与验收

工作台读取 PDF 页面时，`chart_readings` 可返回已校准图中的坐标轴、数据集、曲线名称及终点近似值。每条读数带有源文件和原图哈希、图注定位、像素框、PDF 页内坐标与图像分辨率对应的读数区间。负责人为 ScholarLens 后端维护者。

本次选用 PLOS 论文 `10.1371/journal.pone.0102799` 第 6 页图 4。原图提供 11 组坐标轴及两条曲线的图例。按图中刻度及颜色登记校准信息，每次读取都根据位图像素重新计算纵坐标。作者在表 2 列出了各组的 OLEM、OLTM 结果，供验收程序逐项比对。横坐标终点对应进度 100%。线条断开、遮盖或终点处无法区分时保留缺失。

22 个参考值中返回 8 个，作者给出的 8 个值都落在图像读数区间内。最大绝对误差为 0.0073，平均为 0.00404。另外 7 个子图的 14 个终点保持缺失。Chrome 在工作台显示了相同的 8 个读数，切换页面后旧读数清除。[出版社对照](chart-axis-results.json) · [浏览器记录](chart-axis-browser-results.json)

第二次测试制作了坐标范围、颜色和单位不同的 PDF。向 `SCHOLARLENS_CHART_CALIBRATIONS` 指定新的版本化 JSON 后，从同一读取入口得到 56 和 −1，与绘图输入一致。校准登记绑定 PDF、位图和题注的哈希。未登记图轴的自动识别仍待验证。[第二张图的复测](chart-axis-fresh-results.json)
