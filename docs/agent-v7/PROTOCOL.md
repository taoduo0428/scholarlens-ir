# ScholarLens E11–E17 研发协议

基线为 9610dac，开发分支为 codex/evo-full-product，负责人为项目维护者。输入包括用户研究目标、已授权来源、持久化任务、实验预算。输出包括按论文与问题归属的证据档案、综合报告、运行轨迹、权限边界及本轮可复现实验。

## 研究质量验收

冻结语料使用既有 LFS SHA-256。用固定盐排序，排除旧基准及 V2–V6 报告提及的所有论文，选择 24 个论文对和 4 个三篇组。开发阶段只使用既有诊断语料和合成回归。各策略使用相同论文、相同问题、10 次工具预算和零模型预算；真实供应方另测。双篇综合仍使用 V5 的双来源前提指标。旁列描述、共同研究条件、趋势和因果分别统计。原句题要求与目标论文一致，缺失布局题检查误发。比例报告分子、分母和 Wilson 区间。开放语义的准确率须标明判断来源。111 题沿用已冻结的 AI Silver。

## 产品接口与验收

研究分析以独立策略 E11 接入现有图执行器。结构化候选携带论文、证据 ID 和精确原文区间。服务按用户、语料版本、证据哈希、原句完整性和语义角色复核。每个问题计划列明必要字段、可选字段和接受条件，关系报告保留双方来源和首个缺证环节。项目记忆以用户和项目复合键保存已核证的内容。

PDF、表格、公式和图像以文档哈希、页和区域为证据位置。工具网关按服务端身份验证访问。恢复、并发、窗口隔离、发布审批、备份及恢复需通过实际操作验证。前端使用任务 API 展示报告和花费。所有发布判断以最终代码、实际测试和各项外部依赖的运行结果为依据。
