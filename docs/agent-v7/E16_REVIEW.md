# E16 独立核验的同预算对照

研究评测维护者使用已冻结的 E11 轨迹比较单研究流程与增加一次离线来源复核的流程。两个条件共享每题的输入、论文范围、检索记录和原始候选答案。复核器只接收已发表的陈述。它回查固定语料版本、授权论文、引文区间和哈希，逐条检查摘录型陈述与引文的绑定。验收记录两组可直接回答的任务数、被剔除的陈述、额外调用和本地运行耗时。

## 2026-11-22 结果

| 111 题同预算回放 | 单研究流程 | 加一次离线核验 |
| --- | ---: | ---: |
| 有直接答案的任务 | 12 | 12 |
| 有来源的直接陈述 | 16 | 16 |
| 检索调用 | 294 | 294 |
| 原文回读调用 | 700 | 700 |
| 模型调用、Token、供应商收据 | 0 | 0 |

16 条直接陈述均为原文摘录。复核器逐条核对授权范围、语料版本、字符区间、引文哈希、原句与归属，全部通过。对照实验复用了同一批 994 次工具调用。复核器在固定语料装载后额外用时 0.197 秒，其中包含从磁盘读取 111 份轨迹的时间。[机器结果](e16-current-results.json)

检查中发现旧的离线脚本会用轨迹自报的语料版本参与核对，并且仅凭摘录指向一段真实引文就认可其来源。本次修正后，3 项专项测试验证了原句通过、被改写的数值遭剔除、整条轨迹偷换语料版本时报错。冻结回放中的摘录均通过了修正后的检查。

本批 70 道可答或部分可答题中有 58 道缺少直接答案。只对已发布答案做二次核验无法恢复这些遗漏。本次产品决策为保留现有单研究流程，将第二核验角色用于离线审计。当前实验覆盖的是确定性来源核对。研究问题相关性、结论的语义支持度及调用真实模型的成本仍待带预算的供应方运行和独立标注。真实模型参与的专业分工须通过同预算比较后决定。[研究质量与逐项证据](QUANTITATIVE_EVIDENCE.md)

## 复测

~~~powershell
.\.venv\Scripts\python.exe -m tools.research_eval.v7_independent_verifier output/v7/quantitative-20261122/verified/E11 --output output/v7/e16-repeat.json
.\.venv\Scripts\python.exe -m pytest -q backend/tests/research/test_offline_verifier.py --basetemp=output/v7/e16-pytest-repeat
~~~
