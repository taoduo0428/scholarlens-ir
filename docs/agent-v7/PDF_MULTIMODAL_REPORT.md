## 跨页表格

在 PLOS ONE 的公开论文中，表 1 从第 3 页右栏续到第 4 页左栏。工作台按续表题注、两页表头、单位和各列的相对位置绑定两个物理区域。对于带交替底色、缺少竖线的表，后端从表头分段线和行底色边界读取单元格。跨多列的小标题使用一个完整区域。每个单元格仍以 PDF 版本、页码和边界框定位。[出版社原文](https://doi.org/10.1371/journal.pone.0081798)

逐行对照出版社 JATS 源文件，两页的重复表头对应同一行。合并后的 52 行、4 列含 199 个非空值，全部与原表一致。核对包含数值、符号、单位和行序，行标题的缩进和跨列按 JATS 标记解析。另一篇 12 页论文的 6 张表继续通过原有逐格核对，全篇跨页链接为 0 个。跨页正例来自一篇论文，缺少续表编号、没有重复表头及扫描件的情况仍待验证。[机器记录](table-continuation-results.json)

复测命令为 `python -m tools.research_eval.v7_table_continuation <出版 PDF> <JATS XML> --output <新文件>`。两个输入均按 SHA-256 核对。浏览器回归通过本地服务打开两页合成 PDF，从续页第 2 行第 2 列选取 64，在保存的报告中核对页码和引文，并完成 Markdown 下载、刷新恢复及另一账号的访问隔离。

隔离 ES 的完整后端测试 776 项通过，失败、错误和跳过均为 0，pytest 用时 559.326 秒。原索引文件清单一致，测试端口已释放。PDF 专项 25 项通过，前端 45 项通过，结构检查、TypeScript、生产构建与双账号浏览器回归通过。首次浏览器构建误用了演示数据模式，在登录后的研究问题输入处超时。使用项目 API 模式重新构建后通过。

## 图例文字复核

从原 PDF 提取图 4、5、6 的位图，逐一验证与出版社单独发布的图片具有相同 RGB 像素哈希。使用 Tesseract 5.4.0 英文模型，整图稀疏文字模式命中 12/14 个图例标签。读取预选图例区域时命中 14/14，同时返回 12 个多余词元，其中包括被识别成字母的色块。裁剪、识别模式和文字位置均保留在记录中。参考标签经 AI 看图转录，尚无人工 Gold。

运行 `python -m tools.research_eval.v7_pdf_legend <授权 PDF> --tesseract <可执行文件> --output <新文件>` 可复测。脚本覆盖这一版论文的三个图例，输出图号、原位图哈希、像素位置、原始候选词和引擎置信度。自动图例定位、坐标轴和数值精读仍待产品验收。[逐词机器记录](legend-ocr-results.json)

核验样本是 Pan 等人发表的 *Online Community Detection for Large Complex Networks*，出版社采用 CC BY 4.0。读取同篇论文的 PDF 和 JATS XML，共 12 页，6 张表、6 幅标注图。[出版社原文](https://doi.org/10.1371/journal.pone.0102799)

用 pdfplumber 0.11.11 提取页内区域，对全部返回项检查边界框、坐标系、文档哈希及引文哈希。表格比较只归一化 Unicode、空白和全空分隔行，保留列序、行序、数字、符号及表头。6 张表的 219 个单元格与出版社逐格一致，位于第 6、7、8、10 页。7 个候选中，第 1 页装饰框为误检。单篇命中率不能外推到扫描论文或复杂跨页表格。

公式、图像区域和题注各有类型。该样本返回 7 个图像区域。页级 API 现在按位置匹配编号题注。同页图像和题注须水平重叠、垂直相邻，并且能唯一配对。工作台展示题注原行和双方位置。该论文的 6 幅编号图分别位于第 3、4、5、6、9、10 页。各题注首行均包含对应 JATS 图标题。将 PDF 嵌入位图与出版社另行分发的 6 张大图解码为 RGB 后，6 组尺寸和逐像素 SHA-256 均一致。第 1 页的第七个图像区域保留为无题注区域。该次验收覆盖图注和单页表格。跨页表与图例 OCR 的后续结果见本页相应章节。工作台可在限定论文范围内读取指定页，选择原表单元格。生成报告时，服务在当前账户和任务预算内重新读取单元格，并核对文档版本与引文哈希。报告和 Markdown 保留页、表、物理行列及坐标。

应用提交 `4f0e772` 的完整后端 741 项通过，失败和跳过均为 0，pytest 用时 408.164 秒。图注、表格和报告相关回归 17 项通过。前端 45 项、结构检查、TypeScript 和生产构建通过。浏览器通过两个账号核对题注原行、图像与题注位置、单元格引用、报告导出和恢复。[验收明细](figure-acceptance.json)
