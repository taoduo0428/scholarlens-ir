# 定量证据与原文定义

E11 后端负责处理针对具名研究对象的定量证据请求。输入为用户的问题、授权论文集和本次查阅的原文。若用户同时接受指标定义、实测数值或明确的界，应分别核验已经写明的部分。输出引用完整的原句并保留论文、位置和哈希。另行要求的单位、对照或实验条件须有各自的依据。

验收采用冻结的 111 道 AI Silver 题，以及另一组真实论文中的指标定义。对照包括移除定义、调换研究对象、只在原文中出现数值。逐条回查新发布的原句与量的归属。

## 2026-11-22 回放

原版本把定量问题和对单位、对照、条件的追问各编译为一个通用属性。即使取回明确的定义，这一属性也缺少具名研究对象与原句的对应关系。本次使英文定量提问能逐项接受数值、定义或界，以及原文明确给出的限定。仅询问界时，原文给出定义仍保留缺口。

| 同一份冻结任务 | 改前 | 改后 |
| --- | ---: | ---: |
| 70 道正例有直接答案 | 9 | 12 |
| 21 道缺证题有直接答案 | 0 | 0 |
| 20 道不可比题有直接答案 | 0 | 0 |
| 整题可答性分类符合 Silver | 42/111 | 42/111 |
| 回查通过的来源区间 | 374/374 | 350/350 |
| 回查通过的直接陈述 | 13/13 | 16/16 |
| 成功工具调用 | 1003/1003 | 994/994 |
| 模型调用 | 0 | 0 |

新增的三道题分别涉及不确定数据库的项集支持度、网络可通达性与类别势函数。三个引文均与 Silver 标注原文重叠，整题均只答出了已有证据的部分。正例仍有 58/70 没有直接答案。样本无人工 Gold 标注，41 道负例零误发的 Wilson 95% 区间上界为 8.6%。逐题哈希、字符位置、预算与延迟见[机器记录](quantity-evidence-results.json)。

另从固定真实语料排除既有基准和文档提到的论文，再按摘要含定义句式筛出全部 5 篇。使用固定盐值排序并封存对象与句子哈希后，才运行改前版本和新版本。初次验收发现一句疑问句被当成定义，修正后保留了图的修正离心连通指数的定义。这次修正使用了新样本的反馈，因此最终数据属于迁移回归。

| 另一组真实论文，每项 5 题 | 改前有直接回答 | 改后有直接回答 |
| --- | ---: | ---: |
| 完整摘要 | 0 | 1 |
| 清空目标摘要、保留干扰论文 | 0 | 0 |
| 问原文中不存在的量 | 0 | 0 |

完整摘要中发布的原句与封存的 SHA-256 完全相同。其余四例包含指代、公式缺字、疑问句或难以确认的定义。29 项后端回归通过，覆盖单位、跨分句错配、缺证、单独询问界、已有多跳和描述性问题。
