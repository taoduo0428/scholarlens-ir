# 研究执行与发布契约

W4 使用已签入项目的 LangGraph、SQLite 检查点、原文注册表及报告器。独立开关 `SCHOLARLENS_WORKSPACE_V4=true` 开启新版。任务原文、意图、答案类型、问题依赖、交付物、证据要求、比较条件、预算与语料代次共同绑定至保存的 Answer Contract。旧任务从自身固化的策略继续运行。

研究控制器每轮计算未满足的义务，将缺口关联到现有问题节点。发布时重新读取允许的证据，依次核对来源、命题、答题关系和全部必要条件。直接答案、可参考背景、不可比观察和未完成的义务分别保留。受控样例对所问摘要首句使用一次检索轮次。缺失序列号与计数对象不匹配时保留 partial。

个人模型采用原有提供商配置。标准任务为规划和证据关系判断分别预留一次，深度任务再加入一次动作与一次综合。SQLite 记录模型调用预留，故障恢复时已消费的阶段继续使用确定性路径。正式运行时以单个任务的模型硬上限为准。模型只能返回类型化的子问题、动作、已有来源的关系或结论顺序。
