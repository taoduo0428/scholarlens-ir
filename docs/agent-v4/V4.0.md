本轮在 b81a435 上建立独立工作树，原开发树中的 189 项未跟踪内容保留原位。V3 已使用的 18 个问题在当前代码重跑。V1、V5、V6 均命中 6/6 个机械锚点，实际工具数依次为 136、152、152。三组都在 3/3 道资料缺失题发布了标为已核验的陈述。候选技能在 3 题中触发，指标与 V5 持平。模型调用均为 0，人工研究质量为空。运行记录位于 `output/v4-start/v3-used-replay/summary.json`，冻结策略来自上一阶段的 dev-ablation/policy.json。
