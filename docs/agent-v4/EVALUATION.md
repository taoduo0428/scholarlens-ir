# V4 评测协议与发布边界

基线为用户 fork 的 zjl，提交 b81a435。旧的 18 道题作为已知回归，先重跑 V1、V5 和 V6。用保存的指标摘要校验当时的数字，同时报告当前基线复跑的差异。语义判断仅能由实际标注产生。

本轮实验以锁定 LFS 语料的公开英文摘要为材料，排除旧 seed、review 和 V3 冻结家族使用的论文，按标题主题分配整个家族。训练、开发和独立评估各选两种新家族，每家族选两篇有足够摘要的论文。以固定哈希选择。每个家族生成七道研究任务，覆盖直接原文事实、方法比较、因果链、条件对齐、相反结论、缺失信息和相关背景干扰。题目和题型在实现新策略之前锁定。运行器只得见原问题、权限、论文和代次。可机械验证的直接答案与参考文本的精确匹配、来源原文一致性、可定位引用、缺失项的直接发布次数分别记录。开放比较与因果问题提供待评材料；人类相关性、充分性、任务成功率留待签核。

版本包括 V1、V3 高阶策略 V5、新答案契约门禁、个人模型自适应路径、候选技能、受约束 Harness 参数。每题每组使用相同论文、权限、语料代次与相同的工具上限 10。模型对照单列实际来源和实际调用，受控模型和离线证据模式分列。未授权外部收费模型。独立集仅在实现和候选冻结之后打开。每组输出版本、领域、样本数、行动与预算轨迹、耗时、模型次数、Token 与成本；未知值为空。

正式晋升需要候选在同条件独立任务上改善预先注册的质量信号，有足够人工审核，且无来源、权限、拒答或实际预算退化。没有提高或缺少验证时保留 V1。候选只在隔离 Lab 重放，由操作员审批或回滚。生产策略与模型权限沿用原设置。

## 工程验收

项目组长维护协议。契约和判断绑定原用户、原问题、许可范围、语料、任务和算法版本。任务恢复保持相同约束。桌面、平板和手机验收从研究问题追踪至来源与导出。Lab 的轨迹、双版本差异、失败和版本变更同样从真实运行生成。关闭功能开关时沿用 V1，用户查询只访问自己的任务。
