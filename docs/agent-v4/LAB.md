# 本地 Evolution Lab

Lab 的运行来源是命令行对冻结公共语料的重放。每次试验沿用研究图、注册表、预算、SQLite 与正式报告器。实验库只接受本地运行器生成的对照，私有研究任务不进入训练资料。服务端仅在本机演示应用、实验开关启用且账户通过授权时提供只读浏览。路径、任意 SQL、私有任务 ID 不能用作评测输入。

Explorer 逐题展示计划、调用与原文依据。Arena 要求任务、语料代次、许可和预算一致，模型配置不同的比较标记为跨模式。判定规则分别记录未保留的相关段落、错路由、过早停止、缺乏支持、真实但答非所问、条件不足、错误拒答、无效调用和发布复核失败。每条包含触发依据。

候选仅从经核验的公共训练轨迹提炼，冻结技能与参数后运行独立组。操作员审核与回滚只影响本地实验注册表。保留缺标签时拒绝晋升的决定。
