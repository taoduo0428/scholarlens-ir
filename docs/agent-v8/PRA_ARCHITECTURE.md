# PRA 研究任务与验收契约

明确要求逐步引用的因果路径可由最多三条原文连接组成。三步路径的每一步须来自不同论文，中间对象必须逐字对应。报告展示逐步出处，并提示跨论文的端到端效果仍需验证。缺少任何一步时只显示已有的逐篇证据。

单篇论文的软件名称问题，要求原句同时明确作者使用的软件、操作和对象。模型训练可以直接支持同一模型的构建步骤。引用软件作为对照、提出假设用途或讨论其他对象均不满足该字段。

明确只要求综合各篇研究方法时，逐篇字段只要求已核验的方法。三篇以上可以用相连的已核验方法关系覆盖全部论文。综合中逐条写明关系涉及的论文与证据。缺少连接任一论文的证据时，保留子集关系和未完成的全组结论。

两篇指定论文按单一指标比较时，明确归于作者、带完整实验条件的原文测量值可以满足前置结果字段。此规则适用于未附加实验筛选条件的明确指标提问。最终比较仍独立核验指标、数据集、单位、设置和协议，每篇必须只有一项符合要求的测量。

逐篇综述遇到没有摘要的指定论文时，候选版可以在已授权正文中选取最多四段原文作为读取候选。按段内明确的作者方法、目标和结果选择正文片段，保留原有定位与版本。正文中的逐篇结论需要明确的作者归属和自足的陈述，结果、关系与全组综合各自通过原有核验。验收包括真实无摘要论文对照、同组论文范围和原文回查。

摘要分成多个窗口且其中缺少明确的方法或结果时，可以在首个摘要窗口后提前读一段正文。仅补摘要缺失的字段，原文核验和报告复核沿用现有工具预算。

当综述明确要求各篇的局限或待解问题时，每篇可优先读取一段明确载有作者局限或后续研究议程的正文。该段仍须通过字段核验。首个逐篇窗口先于所有论文的补充窗口。

询问研究结果或性能与其他方法相比如何时，PRA 按结果比较规划，需要匹配的实验条件和比较依据。方法介绍只能充当背景。报告在逐篇小节保留通过字段核验的比较前提，标明它们的用途，保留比较结论的缺证状态。

完整 PRA 的综合输入取自本次字段核验已经接受的陈述。分析阶段新提名的原句须先通过同一套归属、字段和原文检查才能进入综合。排序采用服务端 Claim ID，沿用每次 12 条的预算。

研究后端将待核验陈述和来源片段一起交给分析阶段。对于能在来源中逐字定位且长度在 560 字符内的陈述，模型收到的连续原文窗口应包含整条陈述。分析标签只能引用实际呈现的陈述、证据和支持片段。综合排序只能使用该阶段收到的陈述 ID。验收使用固定回放原文窗口覆盖数和受控模型回执。

询问哪个组件带来最大加速、最低延迟或最高准确率时，研究任务须核验性能比较。普通方法介绍只可作为背景。验收使用缺少消融比较的论文和性能问题。

研究后端负责人维护本轮实验。输入沿用研究问题、授权论文集合、语料版本和运行预算。处理顺序为问题依赖图、逐篇证据档案、关系前提核验、证据补查、答案编译和发布核验。复用现有研究状态和存储。默认策略由独立留出实验决定。

冻结对照为 2026-11-22 本地 E11 候选，包含尚未提交的质量修复。代码分支从与其提交文件树相同的个人仓库 zjl 建立，原始回放只读。研究档案增加的字段需携带原句、来源版本、论文与证据 ID、定位、归属及服务器计算的摘要。模型只能提出候选。字段缺证只影响依赖该字段的结论。

诊断运行在相同的 111 道 AI Silver 题、固定论文范围和每题 10 次工具调用预算下执行。另对历史 28 组、独立的论文组合分别评分。报告分别记录部分作答、全部义务完成、带有已发布核验依据的字段、负例误答及论文组覆盖。系统拆出的字段和 Silver 自由文本要求分别计数。只有经过独立证据复查的结论才能用于效果判断。
