# 论文关系核验

两篇论文可以分别说明算法输出与所需输入。接口比较逐字核对带限定词和单位的数据名称，保留输入和输出方向。报告分别引用两篇原文，将实际连用效果列为待验证项。方法相同且原文明确给出各自用途时，综述也应显示各自用途。

两条受控任务在修复前均缺少接口关系，修复后独立方法比较和综合报告各发布一条有双方出处的接口名称对应关系。改变单位大小写或把第二篇的输入改为输出时，报告撤回关系。固定语料的 3,141 篇摘要中此严格接口语法命中 0 条，其实际领域覆盖仍需扩展。历史 28 组已复跑 84 项，全组综合仍为 1/28。子集关系单列并标注支持的论文。编译和关系用例合计 35 项通过。

实验 D 先按明确的方法名、方法族、应用任务分组，再比较候选论文。每组保留逐篇前提。独立函数 `verify_derivation()` 逐条核对论文、授权范围、版本、原句位置与方法宾语。引入机制位于 `backend/research/pra_relations.py`、`overview.py`、`field_gate.py` 与 `field_publication.py`。不同设置下的结果继续通过既有实验条件比较器处理。

受控案例验证了不同回归方法可属于同一方法族、不同方法用于同一检索任务、中英文论文采用同一方法。移除一个前提、变更方法名、缩小论文范围均撤回了依赖双方的结论。英文与中文对照中的“我们使用”增加了明确作者宾语识别。实验所述方向相反与严格的研究发现冲突分别核验。因果路径仍需独立的因果前提。
