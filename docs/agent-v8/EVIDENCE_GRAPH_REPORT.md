# 任务证据图

实验 C 在报告中增加 `profile_relations`。后端在 `backend/research/pra_relations.py` 中把已核验的档案条目与通过字段核验的 Claim 连接。连接键包含论文、证据 ID 和完整原句。每条边保留论文与 Claim ID、Evidence ID、字符定位、句子 ID、原句摘要、来源版本及适用范围。原有引用与图字段继续用于既有客户端。

有明确语法宾语的方法使用规范名称。对于词表外的方法，作者须在同一句中给出完整方法名称和匹配的首字母缩写。跨论文匹配使用全称，同缩写、不同全称分别建档。其他方法描述以来源句子作为报告对象。方法族与方法本名分别记录，应用任务需在原句明确陈述。独立实验目前没有显示动态命名能提高真实综述覆盖。

在 111 道题中，C 单独运行仍发布了 20 条直接陈述，覆盖正例 16 个系统字段，41 道负例误答数为 0。增设可追溯的关系索引本身未提升回答率。
