## 代码、报告和复核边界

明确要求逐步引证的因果题可以补查缺少的中间连接。在三条明确因果陈述的受控对照中，修复前发布一条局部证据，花费 6 次工具调用。修复后用 9 次调用取得三篇论文的原句，完成路径字段，并按因果顺序导出引用。报告标明这是跨论文推断，端到端效果仍需验证。移除中间连接或篡改其来源哈希后，报告撤回综合。50 项多跳和编译测试通过。20 道原有多跳诊断题中，两版均有 3 道能发布局部事实，完整作答均为 0 道。各题工具调用次数一致。
