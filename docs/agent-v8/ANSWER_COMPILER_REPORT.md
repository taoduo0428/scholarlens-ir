# 答案编译

当三篇以上论文中的一部分支持某项关系，报告在“跨论文关系”注明涉及的篇数和题名。全组综合要求每篇论文都有经过核验的前提。

逐篇小节按通过核验的论文分组，在每组原句前显示对应题名。普通方法比较也可展示双方已发布前提支持的关系。同一方法有明确用途时，分别保留各篇的应用描述，方便读者区分方法和用途。

`backend/research/answer_compiler.py` 从已发布字段恢复逐篇结论、来源与缺口，再由原报告生成器附加 12 个独立小节。每条来源陈述再次核对已发布 Claim、证据、论文和语料版本。综合小节只接受前提可回溯的已发布关系。无依据的部分呈现明确缺证提示。外部论文文本沿用原有 Markdown 转义。

实验 F 单独运行的直接回答数为 15/70，发布字段数为 16/271，与 A 相同。报告编排让读者看到独立字段，目前没有增加新的可答字段。受控浏览器流程验证了带出处的报告，以及下载、恢复会话与账号隔离。
