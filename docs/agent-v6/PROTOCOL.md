# E10 研究与评测协议

开发基线为公开 fork 的 zjl 提交 5dd0cbc，负责人为组长。输入为研究请求、已授权论文及语料版本。服务端输出逐篇观察、原文定位、跨论文前提和仍缺的字段。E10 实验采用独立开关，保留此前各版策略用于同题回放。

六组旧题用于诊断。新测试按固定语料 SHA-256 和种子 scholar-v6-independent-1 对未使用的论文 ID 排序，取前 24 篇，两篇一组。至少有 120 个字符的摘要和标题即可入选。每组运行综述、首句、缺失版面三种问题。原句、坐标误发和双来源综述沿用 v5_compare.score 原始定义。五版策略每次最多调用工具 10 次、模型 0 次。完整轨迹留在本地，公开题目来源 ID、哈希、耗时与每题计数。选定后再开展开发，保留所有失败题。真实模型另行验收。

111 道 E10 评审题由两个独立模型上下文仅凭题目与原始摘要判断。引文按照 Unicode 字符截取后计算 UTF-8 SHA-256。分歧按来源重新核定，难以确认时登记 ambiguous。两份结果封存后才与研究系统输出对照。AI 评审来源记录为 single_model_multi_pass_review，人工 Gold 使用实际人工确认数。

运行验收覆盖任务恢复、来源与账户隔离、计量、前端任务操作。真实 ES 使用仅绑定回环的私有进程和索引。模型联调仅使用项目明确配置的服务凭据。提交目标为独立开发分支和面向 zjl 的 PR。
