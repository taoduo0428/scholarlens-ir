两位评审在 103/111 题的可答性上一致，在其余 8 题上有分歧。其所引论文集合在 111 题上相同。92 题选取的字符区间不同，语义相同的区间和不同语言的改写可以同时成立。按可答性、矛盾定义、主张关联性和未证实推断的范围判断，共 33 题需合并或裁决，其中 25 题的初始可答性相同。另有 3 道两人都标为部分可答的指标题，经复读改判证据不足。这三篇仅给出温控设计意图、笼统推荐实验评价或时变图探索性示例。逐题原判、来源范围和裁决见 disagreements.json 与 adjudication.json。

v3-routing-compare 说明引文准确与完成所问字段可以有不同结果。E9.1 的唯一 verified 候选正确回顾了 TCP 辅助功能的前人研究，其引文和原始字符区间相符。题目所要的两项研究目标是联合决定流量路径与辅助功能位置，以及在受灾信息不完全时安排巡检和恢复。系统给出的直接研究目标有 0 项。其余 110 题的 verified 或 contradicted 候选数均为 0。111 题的直接 verified 主张总数为 0，故其精确率分母为 0。

按题级状态完全相等计，E9.1 为 34/111。逐字段复核覆盖 352 项判定。70 道可答或部分可答题均遗漏了有依据的答复。20 道不可比题拒绝排名有据，但缺少各自条件或评价目标。17 道部署保证题可以拒绝承诺 20% 增益，仍应交代需要的基线、分母及迁移证据。另外 4 道指标题缺乏实际测量，系统把请求处理为跨论文比较。所有失败题均在逐题文件内。结论覆盖历史记录中能够核查的字段、候选、来源以及直接发布的主张。

复核覆盖两位评审共 607 个证据定位、最终标签 312 个定位、历史系统返回的 427 个定位和唯一候选的精确引文。区间以每篇原始摘要的 Unicode 字符计数，起点包含，终点不包含，摘要切片用 UTF-8 编码后计算 SHA-256。逐行记录的 supported_claims 和 unsupported_claims 对应系统实际候选。source_supported_claims 和 source_unsupported_hypotheses 对应阅读原文后得到的证据与边界。

项目根目录执行 python -m tools.research_eval.v6_silver 可用本地原始输入验证任务顺序、文件哈希、来源范围、字符定位和汇总。文件产出时间、盲评范围和使用的裁决规则见 review-manifest.json。
