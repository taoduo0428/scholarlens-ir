# 六组真实论文综述为什么失败

六组题都要求梳理两篇论文的方法、结果、差异和开放问题。E9.1 每组发出 3 次查询，均找到指定的两篇论文，并读到两篇摘要的首个窗口。旧版六组均返回部分可答，分别形成 4、2、2、2、2、2 个字段绑定，跨论文推论为零。系统找到了论文，最先丢失信息的环节主要在读窗、归属识别和依赖关系。逐题的检索词、完整论文 ID、窗口、证据哈希、门禁理由和前提 ID 见 [逐题轨迹摘要](six-cases.json)。

|组|两篇论文及可支持的内容|E10 观察到的环节|判断|
|---|---|---|---|
|0|多层网络渗流与分子优化。前者提出并区分两种渗流模型，后者提出基于分子图文法的优化方法并报告实验。|两个前后窗口各读一遍，共 4 段、14 个绑定，双方的方法和结果齐全，生成有两篇来源的综合描述。开放问题仍缺证据。|原来少读尾部且欠缺方法前提。当前可并列介绍，不能据此按同一指标排名。|
|1|VSDL 描述与约束求解用于虚拟场景建模，另一篇引入广义零因子图并计算直径上界。两者都可陈述目标和技术。|读到 3 个窗口。单篇数学论文取得 2 个绑定，另一篇的作者贡献与上文边界黏连。复合句中的数学上界也没有占到结果字段。最终节点显示 dependency_open。|可以描述两项贡献，拒绝所有综合属于漏答。没有共同实验尺度，拒绝性能排名有据。|
|2|LUCCa 根据局部保形校准处理动力学不确定性，另一篇用多层图动态规划计算多个候选解。后一篇注明部分假设需参看勘误。|读到 3 个窗口、5 个绑定。LUCCa 验证结果已入库，方法字段仍缺，第二篇的方法与结果均进入档案。|摘要支持逐篇方法描述。门禁按现有前提拒绝，最先缺的是方法绑定。勘误细节需补正文。|
|3|一篇给出图除子秩的近似难度界，另一篇用建筑设计案例和平台使用数据研究生成式图像。|读到 4 段、4 个绑定。系统抓到理论结果和应用分析，但两篇均未形成成对的方法与发现。复读可见设计流程属于第二篇的产出。|可以比较研究目标与验证方式。把两项工作视作相互矛盾或按共同指标排序缺乏依据。|
|4|量子视觉 Transformer 提出三类结构，摘要提及医疗图像数据上的模拟。另一篇介绍 LAASP 结构化剪枝，交付摘要在方法句中截断。|3 段、3 个绑定，识别到方法，两边结果字段均缺。量子实验的过去时及被动归属是漏提，剪枝一篇缺少可核查的后续实验叙述。|应发布方法差异并指出剪枝结果缺失。完整双结果综合的拒绝有据。|
|5|动物身份识别通过多模态消融选出编码器与融合方案。另一篇在脉冲网络上研究近似导数训练并报告模型实验。|4 个窗口、18 个绑定。双方方法和结果进入各自档案，综合结论封存各自前提，限制字段保持缺口。|旧版漏答。当前双来源综合通过，两个任务的测量条件仍有差别。|

按这次对摘要的工程复读，E9.1 至少漏掉第 0、1、2、3、5 组可写的逐篇综合，第 4 组的双结果拒绝有材料依据。E10 恢复第 0、5 组，第 1、2、3 组仍漏答，第 4 组仍存在局部漏提。这六组参与过诊断，以上属于开发分析。独立测试另有 12 组。正确拒绝开放问题可以和有据回答方法同时出现。

首轮只增加贡献句提取，开发组仍为 0/6。对比执行轨迹发现方法节点在同一预算内无法消费另一并列节点已经核实的事实。E10 随后把同篇已核实事实接入方法节点，并增加跨文档轮流读窗。最终仍要求逐篇原文验证和双来源前提。

定位时区分 RETRIEVAL_MISS、SOURCE_READ_FAILURE、PARSING_LOSS、QUESTION_DECOMPOSITION_ERROR、FIELD_CONTRACT_ERROR、EVIDENCE_BINDING_ERROR、ENTITY_ALIGNMENT_ERROR、PREMISE_MISSING、SYNTHESIS_FAILURE、CLAIM_UNSUPPORTED、PUBLICATION_OVERBLOCK、SOURCE_CAPABILITY_LIMITATION、MODEL_FAILURE 和 RUNTIME_FAILURE。这六题没有出现找错论文、运行崩溃或模型错误。即使最后一关拒绝，也须追到第一个缺失的字段，不能一概归为门禁错误。
