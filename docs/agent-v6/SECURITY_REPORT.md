# 账户、来源与运行安全验收

|检查|实际执行和观察|证据类别|
|---|---|---|
|任务、事件、报告、Markdown、Evidence|A 创建带原文的任务并成功读取。B 对相同 URL 的读取均得到 404。接口测试使用显式注入的两个测试身份。|确定性 HTTP 集成，test_e10_boundaries.py|
|上传和管理员权限|原生集成通过实际注册登录、私有原件访问、上传审核、向量检索、用户记录和管理操作权限检查。隔离 SQLite、真实 ES 8.19.23 与本机 MiniLM，五组共 163 项路由断言。|live integration，test_upload_integration_isolated.py|
|论文中的控制性文本|受控论文含实际越界来源的标识及发布坐标的假声明。最终证据仅来自授权论文，原句得到保留，版面字段报告来源能力缺口，私人标记未进入报告，指令性文字未成为已核验结论。|确定性 E10 图执行|
|错误来源和实体|已修改的引文、其他节点的证据、与所问实体不符的主张均需经过哈希、节点归属和字段门禁。受控模型建议无法使相应测试的错误声明发布。|test_e9_scope_gate.py、test_e91_hardening.py|
|凭据与用量|回显合成密钥的供应方响应被拒绝。用量缺失保留 null，未知服务地址归为 custom，图进入次数与供应方调用分别记录。真实模型验收仅接受项目配置。|test_service_boundaries.py、test_runtime_receipts.py|
|观测所有权|任务详情按用户返回 trace_ids、graph_attempts、graph_reentries。真实 span 存在时才有 Trace ID。已提交的工具动作、错误码、预算和 provider_usage 可按同一任务找回。旧任务缺计数时显示 null。|test_e10_operational.py、test_process_resume_v3.py|
|损坏、锁和并发|损坏任务隔离；独立账户仍可执行。写锁持有期间另一写入等待，释放后仅提交一次。进程真正中断后重开，证据哈希保留，图执行次数为 2。|SQLite、子进程恢复实测|

威胁覆盖限定于上述测试及其断言。论文原文属于不可信数据，报告的来源区域可以忠实展示原文，实际安全判断依赖访问范围、工具动作和最终发布结果。真实供应方对抗行为、生产渗透测试和线上账单均缺少本轮观测。

本轮源码差异接受 Gitleaks 脱敏扫描，前端 npm audit 和 Python 锁版本 pip-audit 的结果列在验收清单。公开评审只给定位、哈希、独立改写和聚合数，原件和完整轨迹留在本地。扫描结果不能量化未知漏洞发生率。
