## 2. 应用、架构与容器安全人工审查结论（20 域核查）

- **认证、越权与账户保护**：密码采用 16 字节随机盐 + `scrypt (N=16384, r=8, p=1)`；会话 Token 经哈希入库支持注销与重置吊销；研究任务/工作区/收藏/上传按 `user_id` 强隔离，跨用户返回 `404`，非管理员请求 `/api/admin/*` 与 `/api/evolution-lab/*` 严格返回 `403`。
- **上传与路径遍历防御**：`UploadLimitMiddleware` 在 multipart 解析落盘前强拦截超 21 MiB 请求并验证认证；`verify_pdf` 校验 `%PDF-` 文件头、拒绝加密及超 300 页 PDF；`tei_to_paper` 显式拒绝 `<!DOCTYPE`/`<!ENTITY` 防 XXE；`resolve_pdf` 校验路径完全约束在 `resolve(strict=True)` 根目录下。
- **个人 AI 代理与 SSRF 防御**：`PublicAITransport` 强制仅允许公共 HTTPS 443 端口且无查询/认证段，并在拨号层拦截内网、环回及保留 IP（防 SSRF/DNS Rebinding）；模型返回若意外包含用户密钥立即拦截报错，全日志与 OTel 均脱敏。
- **容器与编排加固**：应用镜像采用非特权 `UID 10001`、`--read-only` 根文件系统、`cap_drop: [ALL]`、`no-new-privileges:true`、剥离 `pytest`/`ruff`；OCR 镜像 `scholarlens-tesseract` 经 `build-png-ocr.sh` 最小化编译剔除 `libcurl`/`libtiff`/`libxml2`/`libarchive`。
