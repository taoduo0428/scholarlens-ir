# ScholarLens 用户使用指南 (User Guide)

欢迎使用 **ScholarLens EvoResearch** 学术论文检索与证据驱动研究工作台。本指南帮助研究者与管理员快速上手全部核心功能。

---

## 1. 账户注册、登录与个人空间

1. **注册与登录**：点击右上角 **账户** 进入 `/account`，使用 3–64 位字母数字下划线用户名与至少 10 位强密码注册并登录。登录凭证在当前浏览器会话内有效，刷新页面不会丢失登录状态。
2. **我的文献 (`/library`)**：
   - 在检索列表或论文详情页点击 **加入收藏**，可为论文创建自定义分类、添加阅读笔记，或将正文摘录一键追加至笔记。
   - 浏览器与服务端同步保存最近阅读记录和上次阅读进度，支持导出与导入 JSON 阅读空间备份。
   - *数据隔离说明*：您的收藏、分类、历史与研究任务均与个人账户严格隔离，其他用户无权访问。

---

## 2. 论文检索、浏览与全文定位

1. **多模式检索 (`/` 与 `/search`)**：
   - 支持 **关键词 (BM25)**、**语义向量 (MiniLM)** 与 **混合 (RRF)** 三种检索模式。
   - 可限定检索字段（全部、标题、作者、日期、机构、地址、全文），勾选精确短语或模糊匹配，并按年份区间过滤与排序。
2. **论文详情与原文核对 (`/paper/:paperId`)**：
   - 展示结构化元数据、摘要、全文段落与 PDF 在线阅读器（当服务器已挂载合法原件时支持分片预览与下载）。
   - 研究报告中的每一条 **已定位证据** 均可一键点击 **定位到论文原文**，自动打开对应论文并精准高亮该引文起止字符区间。

## 3. 深度研究工作台 (`/research`)

ScholarLens 深度研究工作台能够将复杂学术问题拆解为结构化子问题，自动检索本库论文，经过严格的原文回读核验与跨论文冲突分析后生成带逐条出处的学术研究报告：

1. **选择研究模式**：
   - **只读证据模式 (`evidence_only`)**：无需配置外部大模型密钥，纯基于本地索引与规则语义槽提取、交叉对比，并输出 100% 经过原文定位核验的可答证据与缺口分析。
   - **使用个人模型模式 (`personal_model`)**：前往 **证据助手 → API 设置**（`/assistant`）填写您的个人 HTTPS 模型接口地址、模型名称与 API Key（个人密钥仅保留在当前浏览器会话中，仅在任务请求时发送，绝不落盘到服务器或泄露给其他用户）。
2. **创建并追踪研究任务**：
   - 填写研究问题，可选填 **研究项目标识**（用于在项目看板聚合查看耗时 p50/p95 与 Token/成本统计），并可展开 **本库论文范围** 限定具体论文 ID 或包含本人已审核入库的上传论文。
   - 提交后页面实时展示：
     - **答案契约与研究问题 DAG**：可展开查看每个子问题及其依赖关系、完成条件与待核查缺口。
     - **执行记录与工具明细**：透明追踪每轮检索、原文回读与耗时。
     - **逐篇研究档案 (`Research Profiles`)** & **综合研究**：按论文结构化归档研究目标、方法、作者贡献、数据集、指标、实验条件、基线与发现，并明确标注作者观点与引述前人研究的边界。
     - **研究报告与导出**：严格区分“直接可答结论”“前提背景”“实验条件不可比”“存在矛盾的观察”与“证据不足”；支持一键 **导出 Markdown** 和 **导出任务 ZIP**（包含完整 manifest、状态、事件与全部已核验产物及 SHA-256 校验和）。
     - **任务追踪**：在任务卡片下方展开 **任务追踪** 可复制 `trace_id`（当部署配置了 Jaeger 网关时可直接点击 **在 Jaeger 查看** 全链路耗时 Span）。

## 4. PDF 上传审核与管理员控制台

1. **普通用户上传 (`/upload`)**：
   - 支持两种工作区：**服务端上传**（上传不超过 20 MiB、300 页且未加密的 PDF 提交管理员审核，审核通过并处理后纳入独立上传检索库）与 **本机文件**（仅保存在浏览器 IndexedDB，方便离线预览与整理）。
2. **管理员工作台 (`/admin` 与 `/evolution-lab`)**：
   - 管理员可预览用户上传的待审 PDF、填写意见并批准或拒绝、触发解析向量化入库或归档，并管理用户启用状态。
   - 当部署开启 `SCHOLARLENS_EVOLUTION_LAB=true` 时，管理员可访问 `/evolution-lab` 对比冻结基准实验数据及已批准策略版本信息。
